# Álvaro Martínez González - Portafolio

## Descripción
Portafolio profesional de Álvaro Martínez González, **Ingeniero Civil en Computación** y desarrollador Full Stack. Aquí presento los proyectos en los que he trabajado, demostrando experiencia en:

- **Desarrollo web y móvil** con tecnologías modernas (Astro, React, Flutter, Node.js, etc.).
- **Aplicaciones de alta disponibilidad**: arquitecturas tolerantes a fallos, despliegues automatizados, monitoreo activo y estrategias de respaldo para garantizar continuidad operativa.
- **Procesos de datos pesados**: tareas asíncronas con **Celery** y arquitecturas de **microservicios** que se comunican entre sí mediante **Redis** y **BullMQ** como brokers de mensajes, logrando paralelización y reduciendo tiempos de respuesta en workloads intensivos.
- **Infraestructura cloud**: despliegues en **VPS**, **Docker** para entornos reproducibles y pipelines de **automatización de despliegues** (CI/CD).

## Stack Técnico
- **Frontend**: Astro, React, TypeScript
- **Backend**: Node.js, Python, FastAPI, Flask
- **Mobile**: Flutter
- **Bases de datos**: PostgreSQL, MongoDB, MySQL, Firebase
- **Infraestructura**: Docker, despliegue continuo
- **Procesos async**: Celery, Redis, BullMQ

## Características del sitio
- Diseño responsive optimizado para dispositivos móviles.
- Carga rápida gracias al prerenderizado de Astro.
- Imágenes optimizadas automáticamente (WebP) vía `astro:assets`.
- Animaciones suaves y efectos visuales, con soporte para `prefers-reduced-motion`.
- Sitemap y Open Graph para SEO.
- Accesibilidad: skip-link, focus-visible, ARIA labels, focus trap en modal.

## Requisitos
- **Node.js** >= 20
- **pnpm** >= 10

## Instalación y desarrollo

```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm dev

# Build de producción (incluye astro check)
pnpm build

# Previsualizar el build
pnpm preview
```
